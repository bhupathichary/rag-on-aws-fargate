# Amazon S3 (Simple Storage Service)

S3 is object storage: you store files ("objects") in "buckets". Bucket names are globally unique.
Designed for **11 nines (99.999999999%) durability**. Not a filesystem — flat key namespace.

## Storage classes (cost vs access trade-off)
- **S3 Standard**: frequent access, 99.99% availability, multi-AZ.
- **S3 Intelligent-Tiering**: auto-moves objects between tiers based on access — no retrieval fees.
- **Standard-IA** (infrequent access): cheaper storage, retrieval fee. Multi-AZ.
- **One Zone-IA**: single AZ, cheaper, less resilient.
- **Glacier Instant Retrieval**: archive, milliseconds access.
- **Glacier Flexible Retrieval**: minutes-to-hours retrieval.
- **Glacier Deep Archive**: cheapest, 12-hour retrieval. Long-term compliance.

## Key features
- **Versioning**: keep multiple versions; protects against overwrite/delete. Once enabled, can only be suspended.
- **Lifecycle rules**: auto-transition to cheaper classes or expire objects after N days.
- **Encryption**: SSE-S3 (AWS-managed), SSE-KMS (KMS keys + audit), SSE-C (customer keys), DSSE-KMS (dual). Encryption at rest can be enforced by default.
- **Bucket policies** (resource-based) and **IAM policies** (identity-based) control access. **Block Public Access** is on by default.
- **Pre-signed URLs**: grant temporary, time-limited access to a private object.
- **Static website hosting**: serve HTML directly from a bucket (no server).
- **S3 Transfer Acceleration** and **Multipart Upload** for large/fast transfers.
